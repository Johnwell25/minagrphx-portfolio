Process

Four stages, in order.

01 — Discover

Read the constraints

Audience, format, budget, print vendor, screen size — the real limits, before any concept work starts.

02 — Define

Set the grid

Columns, type scale and spacing get fixed early — every later decision is judged against this structure.

03 — Design

Work inside it

Concepts are built on the grid, not laid over it after the fact. If it doesn't fit, the grid was wrong.

04 — Deliver

Hand off the system

Files, guidelines and source grids — so the identity holds up in someone else's hands, not just ours.
